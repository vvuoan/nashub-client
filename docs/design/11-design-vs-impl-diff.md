### 0.3 按根因去重

255 处里大量是「同一个 CSS 值在多个状态重复」。去重后约 **75 条独立缺陷**，其中 **45 条**集中在下面 5 个簇，其余为零散项：

| 簇 | 独立条数 | 影响面 | 结论 |
|---|---|---|---|
| 详情页垂直节奏（头部 38u 内边距 + 标题行高 1.1） | 18 | 详情 7 态、订阅 3 态 | 全链路累积下移 16–56u，最严重 |
| 影视分类页结构（标签、行标题、行距） | 12 | 电影/剧/动漫/收藏/列表态 | 首屏卡片位置与画布不同源 |

| 订阅电视剧/番剧结构（右侧资料卡缺失） | 5 | 订阅 2 态 | 分集区整块落到一屏之外 |
| 设置外壳尺寸（开关、内边距、导航间隔） | 7 | 设置 10 组 | 视觉可辨但影响小 |

### 0.4 最直观的 5 个问题

1. **订阅电视剧/番剧没有右侧资料卡**：画布 `620×560 @1300,356`，实现把演职人员与影片信息整宽下排，分集区从 `y723` 掉到 `y1159`（一屏之外）。
2. **详情页头部整体下移**：眉标 `+28/+30`、片名 `+36`、元信息 `+32`、按钮 `-40`。
3. **影视分类页缺分类标签**：电影/剧/动漫/收藏四个页面在没有 tag 数据时只剩「筛选」一颗胶囊。
4. **收藏分组节奏差 77u**：第二组标题 `y543` vs 画布 `620`。
5. **播放源浮层横向溢出**：选项行 `520u` 宽，面板只有 `320u`。

## 1. 口径、方法与环境

### 1.1 画布侧

- 通过 ardot MCP `batch_read` 读取节点真实值（`readDepth 2–6`），大结果落 JSONL 后按节点解析；解析脚本见附录。
- 读取属性：绝对坐标、宽高、圆角、填充、描边、阴影、blur、字体族/字号/字重/行高/字距、子元素间距、层级顺序。
- 画布画板均为 1920×1080；组件板（卡片信息层、导航栏、筛选胶囊）单独放在画板外，坐标按组件内相对值使用。

### 1.2 实现侧

- 真实 Tauri 窗口，通过 CDP `Runtime.evaluate` 读取 `getBoundingClientRect()` 与 `getComputedStyle()`。
- 原始窗口视口为 `1707×1067` CSS px（16:10），会造成 u 坐标纵向多出 120u。为保证与 1920×1080 画布同单位、同比例：
  - 用 `Emulation.setDeviceMetricsOverride` 固定为 `1707×960 @1.5x`；
  - 此时 `--u = 1707/1920 = 0.8889`，视口恰好 `1920×1080u`；
  - 截图输出 `2560×1440`，与画布同比例。
- 所有数值换算：`u = px / --u`，四舍五入到 0.1u。

### 1.3 数据态说明（重要）

本次审计**没有连接后端**，预览路由使用占位数据。因此：

- 文本类元素（片名、简介、元信息）在实现侧渲染为占位条，其**高度与画布文字不同**；
- 由内容高度驱动的后续元素坐标会连锁偏移，这类偏移在明细表里标注「占位态/数据驱动」，不计入 token 级错误；
- 由 CSS 固定值（位置、尺寸、圆角、间距、字号）造成的偏差一律计为硬差异。

### 1.4 三类已知不可比项

| 项 | 现象 | 处理 |
|---|---|---|
| 文本颜色 | 画布变量解析后统一回落为 `#010101`/`#000100`，与实现的浅色文字完全不同 | 判定为 MCP 变量解析异常，**不纳入差异** |
| 字体族 | 画布 `Inter` / `Noto Sans SC`；实现为打包的 `Nastv SF Pro Text` / `Nastv Inter` / 苹方 | 本项目既定的本地字体打包策略，标注「有意偏差」 |
| 字距 | 画布文本多为 `letter-spacing: 0`，实现标题 token 带 `1`（u） | 计入低severity近似项 |

### 1.5 严重度定义

| severity | 判定 |
|---|---|
| 高 | ≥20u 的位置/尺寸偏差；首屏可见性受损；状态不可达；横向溢出 |
| 中 | 10–20u 偏差；字号/行高/圆角肉眼可辨；信息层级错位 |
| 低 | <10u；占位态特有；不影响阅读顺序 |

### 6.3 测量限制

1. **窗口焦点**：Tauri 窗口未获得 OS 焦点时，`element.focus()` 只更新 `activeElement`，不派发 `focusin`、`:focus` 也不生效。列表态通过手动派发 `focusin` 触发；磁贴聚焦态按 CSS 推导，未实拍。
2. **无后端**：所有文本为占位条，文字高度与真实内容不同；已把由此产生的偏移标注为「占位态/数据驱动」。
3. **画布文本色**：变量解析回落 `#010101`，颜色维度未参与比对。
4. **字体族**：画布 `Inter/Noto Sans SC`，实现为打包字体，属既定偏差；字号/字重/行高仍按数值比对。
5. **未逐帧核对**：设置十组只逐组核对了外壳与行数，组内控件细节（如网络组输入框）未逐像素展开；如需可追加专项审计。
