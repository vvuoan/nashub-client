# 13 · UI 交互与视觉规范（焦点 / 滚动 / 版面）

> 本文件是 ardot 画布之外、由实机评审确认的**交互与视觉规范**，与画布标注冲突时以此为准。
> 对应 token 位于 `client/nastv-tauri/src/styles/tokens.css`（`--rows-fade`、`--card-focus-ring`、`--live-preview-w`、`--live-info-w`、`--live-guide-h`、`--live-guide-ch-w`、`--live-row-h`、`--live-now-line`）。

## 1. 焦点路径

| 规则 | 说明 |
|---|---|
| 主视觉优先 | 从导航栏进入影视页，焦点先到主视觉操作区（播放 / 详情），再按 ↓ 进入海报墙 |
| 主视觉 → 海报墙 | 在 `.lhero-actions` 内按 ↓，候选集排除左侧导航项，直接进入海报墙 |
| 导航 ≠ 确认 | 导航栏、分类标签、直播分组、设置分组、季标签：**焦点移动即切换**，无需确认键 |
| 回导航栏 | 从内容区按 ← 回到离开导航栏时停留的那一项（按 `data-focus-key` 记录），不落到几何最近的项 |
| 确认只用于动作 | 确认键仅保留给「播放 / 进入详情 / 首页入口 / 展开收起的外壳操作」 |

实现位置：`src/focus/spatial.ts`（几何导航 + `onBeforeMove` 拦截）、`Shell.tsx`（导航回位）、`NavRail.tsx`、`CategoryTabs.tsx`、`LiveChannelList.tsx`、`SettingsPage.tsx`、`DetailPage.tsx`。

## 2. 导航栏状态记忆

- 离开导航栏时记住**最后停留的导航项**；从内容区回到导航栏（← 或左侧「展开」标签）时回到该项，不重置为路由默认项。
- 导航栏展开/收起由焦点位置决定（首屏列表区收起），返回时保持离开时的展开状态，不额外重置。
- 实现：`src/components/Shell.tsx` 的 `lastNavKey` / `wasInNav`。

## 3. 卡片焦点框

| 项 | 规则 |
|---|---|
| 形态 | 内描边（inset），宽度 `--card-focus-ring = 2.5u`，颜色 `--w-92` |
| 绘制层 | 画在 `.mcard-art::after` 上，覆盖封面图，**不得使用外描边/外阴影**（会被列表容器裁切） |
| 封面描边 | 卡片封面**不加** 1u 高光描边（1.333 设备像素下会出现断线残留） |

实现：`src/styles/home.css` 的 `.mcard-art::after` / `.mcard:focus .mcard-art::after`。

## 4. 列表行组（标题 + 卡片）

- 一行 = 列表名称 + 卡片组，视为**一个组合**：滚动定位以 `.crow` 整组为准，不得只把卡片顶到上沿而把名称甩出视口。
- 组高 ≤ 可视窗：可整体对齐底部，名称保持可见。
- 组高 > 可视窗：名称与卡片上沿一起进入视口，卡片允许被裁。

实现：`src/focus/spatial.ts` 的 `focusSmooth()`（按 `.crow` 计算定位、读取容器 `padding-top` 作为可视上沿）。

## 5. 海报墙滚动与渐隐

- 列表滚动统一 `behavior: smooth`，禁止浏览器瞬移。
- 影视海报墙容器向上延伸 `--rows-fade = 96u`（`padding-top` 等量抵消，未滚动时排版不变），内容滑入上半区（主视觉区域）后在该段距离内**渐隐至全透明**。
- 渐隐只在 `scrollTop > 0`（`.rows.is-scrolled`）时启用；未滚动时标题清晰。
- 分类页（电影 / 电视剧 / 动漫 / 收藏）沿用容器内 64u 渐隐。

实现：`src/styles/home.css`（`.rows` 系列规则）、`src/pages/LibraryPage.tsx`（`is-scrolled` 状态）。

## 6. 主视觉与海报墙交界

- 缩小态主视觉（`560u` 高）下沿增加 200u 渐变，尾部压到纯页底色 `#050708`，与海报墙区域无缝衔接。
- 渐变层不得压住主视觉文字/按钮（`.lhero-body` 提升到 `z-index: 1`）。

实现：`src/styles/home.css` 的 `.lhero.shrink::after`。

## 7. 直播页版面与节目单

### 7.1 版面

| 区域 | 尺寸 |
|---|---|
| 上排 · 频道列表 | 396u |
| 上排 · 直播画面 | `--live-preview-w = 980u`（16:9 → 551u 高，垂直居中） |
| 上排 · 正在播信息 | `--live-info-w = 400u` |
| 下排 · 节目单课程表 | 整幅 1824u × `--live-guide-h = 300u` |
| 间距 / 边距 | 24u / 48u |

上排高 = 896 − 300 − 24 = 572u。节目单不再挤在 400u 右栏：改为整幅横贯的课程表，画面维持 980u，原本画面下方的频道信息移到右栏。

实现：`src/styles/pages.css` 的 `.live-grid`（`grid-template-areas`）、`.live-center`、`.live-info`。

### 7.2 节目单课程表

| 项 | 规则 |
|---|---|
| 方向 | 时间横向、频道纵向：一个频道一行，节目按时段宽度铺开 |
| 时间窗口 | 3 小时；起点 = 当前时刻所在整 30 分钟再往前退一格；刻度 30 分钟 |
| 频道列 | `--live-guide-ch-w = 220u`；行高 `--live-row-h = 44u` |
| 节目块 | 按节目时长占窗口比例定位宽度；左端被窗口裁掉的块不显示开始时间；块宽不足 11% 时省略时间 |
| 当前档 | 正在播的块提亮；选中频道的当前档用白底黑字，与左侧选中频道一致 |
| 已播完 | 当前时刻之前的块淡化（`opacity 0.4`） |
| 当前时刻线 | 一条 `--live-now-line = #e5484d` 竖线 + 表头圆点，贯穿表头与每一行；画在节目块之上，行间不允许断线 |
| 滚动 | 纵向滚动；切换选中频道时把对应行滚进视口；底部 18u 渐隐提示还有更多行 |
| 取数 | 前 12 行预取（每频道 20 条）；其余行进入视口再按需取，同一频道只请求一次；失败写空节目单结束骨架 |

实现：`src/components/media/LiveGuide.tsx`（时间窗口、比例定位、IntersectionObserver）、`src/hooks/useLivePage.ts`（`epgBoard` / `loadEpg`）、`src/styles/pages.css`（`.live-tl-*`）。

### 7.3 正在播信息栏

- 右栏只放选中频道的实时信息：红点「正在直播」+ 频道名 + 当前节目 + 起止时间 + 正在播 / 下一档 + 遥控提示。
- 内容整列垂直居中，遥控提示贴列底；不重复放节目单列表。

实现：`src/components/media/LiveNowPanel.tsx`。

## 8. Token 对照

| token | 值 | 用途 |
|---|---|---|
| `--rows-fade` | `96u` | 海报墙上滑渐隐距离 = 容器向上延伸量 |
| `--card-focus-ring` | `2.5u` | 卡片内描边宽度 |
| `--live-preview-w` | `980u` | 直播画面上排列宽 |
| `--live-info-w` | `400u` | 直播信息栏列宽 |
| `--live-guide-h` | `300u` | 节目单课程表整幅高度 |
| `--live-guide-ch-w` | `220u` | 课程表频道列宽 |
| `--live-row-h` | `44u` | 课程表行高 |
| `--live-now-line` | `#e5484d` | 当前时刻分割线与圆点 |

## 9. 其他版面约定

| 位置 | 规则 |
|---|---|
| 设置页分组 | 单列，宽度收到最长分组名（`max-content`），按钮贴合文字左右各 18u 内边距，不铺满整列；行高 46u、间距 6u |
| 海报墙行 | 卡组单行横向滚动（`.crow-cards` 不换行，海报墙本身不平移）；焦点往右走到行尾时追加下一页，可一直翻下去 |
| 标签结果页 | 多行网格，保留换行（`.tagview .crow-cards` 覆盖） |
| 下载卡收起 | 只隐藏第 4 条起的任务行，标题计数始终为后端返回的总数 |
