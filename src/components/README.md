# src/components/ — 跨页面复用组件

| 文件 / 目录 | 作用 |
|---|---|
| `Shell.tsx` | 应用外壳：导航栏、背景、焦点环与页面容器 |
| `base/` | 与业务无关的基础控件（按钮、焦点、弹层、骨架、进度…） |
| `media/` | 与媒体内容绑定的组件（海报卡、货架、节目单、播放控制…） |

## 放这里还是页面里

- 两个以上页面会用 → 放 `components/`。
- 只服务单个页面且无复用价值 → 留在 `pages/` 内部，不提前抽象。
- 不含业务概念、可被任意界面复用 → `base/`。
- 依赖媒体字段（海报、频道、剧集） → `media/`。

## 约束

- 每个组件都要实现加载态与空态；可选实现错误态，见 `docs/design/14-component-state-contract.md`。
- 可聚焦元素必须使用 `base/Focusable.tsx` 或 `FocusScope`，不要自己监听方向键。
